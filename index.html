Frequently Asked Questions

Everything You Need to Know

Detailed technical and business answers for founders, investors, and engineers.

CSM exposes a native streaming Model Context Protocol (MCP) HTTP server (`/wp-json/csm/v1/mcp`). When building on Lovable, Cursor, Bolt, or v0, the developer or merchant supplies the MCP endpoint and Bearer token. The AI agent inspects CSM’s tool catalog and autonomously wires every button, cart hook, product grid, and checkout form to production backend endpoints with zero manual coding.
CSM never stores raw credit card credentials in plain text. It leverages strict client-side tokenization via Stripe Elements / PayPal SDK, combined with strict server-side HMAC webhook signature validation (`CSM_Stripe::check_webhook()`). Furthermore, checkout enforces per-cart cryptographic CSRF tokens (`X-CSM-Cart-CSRF`) to prevent session forgery and request hijacking.
Shopify is a closed SaaS walled-garden that charges monthly subscription fees, takes up to 2.0% transaction surcharges on non-Shopify-Payments, and restricts database access. CSM is 100% agent-native from day one, offers complete sovereign database ownership, charges 0% transaction fees, and provides 317+ specialized MCP tools allowing AI agents to fully manage your inventory, returns, flash sales, and customer service.
CSM follows a proven open-core + managed cloud model:
  • Open Core: Free self-hosted WordPress plugin for individual developers and small merchants to drive viral bottom-up adoption.
  • CSM Cloud Gateway (managed subscription tiers): Managed zero-setup MCP streaming proxy, multi-store orchestration, and automatic latency routing.
  • Enterprise Sovereign Fleet: Dedicated high-concurrency instances with automated disaster recovery, SLA, and custom ERP connectors.
The engine is a shipping WordPress plugin (v1.76.9) covering products, orders, returns, payments and support through 317 registered MCP tools, proven on a named headless storefront client. Reference stores and a live demo endpoint are available to qualified investors under NDA.
