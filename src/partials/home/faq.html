CSM exposes a native streaming Model Context Protocol (MCP) HTTP server (`/wp-json/csm/v1/mcp`). When building on Lovable, Cursor, Bolt, or v0, the developer or merchant supplies the MCP endpoint and Bearer token. The AI agent inspects CSM’s tool catalog and autonomously wires every button, cart hook, product grid, and checkout form to production backend endpoints with zero manual coding.
CSM never stores raw credit card credentials in plain text. It leverages strict client-side tokenization via Stripe Elements / PayPal SDK, combined with strict server-side HMAC webhook signature validation (`CSM_Stripe::check_webhook()`). Furthermore, checkout enforces per-cart cryptographic CSRF tokens (`X-CSM-Cart-CSRF`) to prevent session forgery and request hijacking.
